Install Kiro agents

Start in one command.

Copy the Markdown source definitions and JSON Kiro CLI profiles together. Use a global install across projects or scope the fleet to one workspace.

02 / QUICK START
Global installationALL PROJECTS
git clone https://github.com/awskrishnak/kiroweaver.git ~/kiroweaver
mkdir -p ~/.kiro/agents
cp ~/kiroweaver/*.md ~/kiroweaver/*.json ~/.kiro/agents/
Workspace-local installationONE PROJECT
mkdir -p .kiro/agents
cp /path/to/kiroweaver/*.md /path/to/kiroweaver/*.json .kiro/agents/
