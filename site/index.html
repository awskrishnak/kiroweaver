Specialized Kiro agents

Focused models, controlled delegation.

Each profile has a defined model, tool scope, permission boundary, and task role. The orchestrator routes work to the specialist instead of relying on one general-purpose agent.

Install Kiro agents

Global or workspace-local.

Copy the Markdown source definitions and JSON Kiro CLI profiles together. Use global installation across projects or keep the fleet scoped to one workspace.

Global installation

git clone https://github.com/awskrishnak/kiroweaver.git ~/kiroweaver
mkdir -p ~/.kiro/agents
cp ~/kiroweaver/*.md ~/kiroweaver/*.json ~/.kiro/agents/

Workspace-local installation

mkdir -p .kiro/agents
cp /path/to/kiroweaver/*.md /path/to/kiroweaver/*.json .kiro/agents/
